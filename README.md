# React Investment Calculator

A simple investment calculator built with React and Vite.

## Features

- Calculate investment growth over time.
- Enter an initial investment and annual contributions.
- Set an expected annual return rate.
- Choose the investment duration in years.
- View yearly investment results, including interest earned and investment value.

## Technologies Used

- React
- JavaScript
- Vite
- CSS

## Getting Started

1. Clone this repository.
2. Install the dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL shown in your terminal.
